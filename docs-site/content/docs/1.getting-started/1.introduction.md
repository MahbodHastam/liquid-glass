`@mahbodhastam/liquid-glass` renders liquid glass for **Vue 3** and **Nuxt** with **WebGL2 shaders**: refraction, lens distortion, chromatic aberration, frost and edge lighting. It works in every modern browser, not only Chromium.

:glass-demo

## How it works

WebGL cannot read the pixels behind a canvas, so each lens needs a [backdrop source](/docs/guide/backdrops) to refract: an `<img>`, `<video>` or `<canvas>`, or a DOM snapshot of arbitrary HTML.

- Frames render **on demand**. Idle means zero `requestAnimationFrame` and zero GL calls.
- One shared WebGL2 context serves every lens on the page.
- Where WebGL2 is missing, or a user preference asks for it, a CSS `backdrop-filter` fallback stays in place.

## Requirements

- Vue ≥ 3.4 (tested on 3.4 and 3.5)
- Nuxt ≥ 3.13, including Nuxt 4
- A browser with WebGL2: Chrome/Edge, Firefox, Safari 15+ (desktop and iOS)
