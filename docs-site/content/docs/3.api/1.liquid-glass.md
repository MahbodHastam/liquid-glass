Everything is optional. Defaults can be changed globally through the plugin or the Nuxt module's `defaults`.

## Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `as` | `string` | `'div'` | The root tag |
| `radius` | `number \| 'auto'` | `'auto'` | `'auto'` reads the computed `border-radius`, so Tailwind's `rounded-*` classes work |
| `blur` | px | `12` | Blur of the backdrop |
| `refraction` | 0 to 1 | `0.3` | How far the rim bends the backdrop |
| `zoom` | 1 or more | `1.1` | Magnification |
| `aberration` | 0 to 1 | `0.2` | Colour split at the rim. `0` removes two texture reads per pixel |
| `frost` | 0 to 1 | `0.08` | Fine static grain |
| `light` | 0 to 1 | `0.3` | Strength of the highlight on the rim |
| `lightAngle` | deg | `-55` | Where the light comes from |
| `edgeGlow`, `edgeWidth` | 0 to 1 | `0.4`, `0.25` | Glow just inside the edge, and how wide it is |
| `tint` | CSS colour | `'transparent'` | Mixed over the glass according to its alpha |
| `opacity` | 0 to 1 | `1` | |
| `source` | element | none | The `<img>`, `<video>` or `<canvas>` to refract |
| `interactive` | `boolean` | `false` | Highlight follows the pointer. Off under reduced motion |
| `quality` | `'auto' \| 'high' \| 'medium' \| 'low' \| 'off'` | `'auto'` | |
| `reducedMotion` | `'auto' \| 'static' \| 'fallback' \| 'ignore'` | `'auto'` | See [Accessibility](/docs/guide/accessibility) |
| `disabled` | `boolean` | `false` | Always use the CSS fallback |

## Events

- `ready`: the shader is running.
- `fallback(reason)`: the lens is using CSS, and `reason` says why.
- `contextlost`, `contextrestored`: the browser dropped or gave back the WebGL context.

## Exposed

`refresh()`, `relayout()`, `isWebGL`, `quality`.

The lens is re-measured after every Vue re-render and on scroll and resize. If something moves it that Vue doesn't know about, like a CSS animation or direct style writes, call `relayout()`. It costs one `getBoundingClientRect` on the next frame.
