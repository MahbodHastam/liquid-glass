title: Performance
description: Rendering model, budgets and measured numbers.
---

- One WebGL2 context per page, created on first mount and released when the last lens unmounts.
- Frames render on demand only. Idle means zero `requestAnimationFrame` calls and zero GL calls; e2e tests verify this.
- The blur (dual Kawase) is computed once per backdrop change and cached. The glass pass reads 1–3 texture taps per pixel.
- Off-screen lenses and background tabs don't render.
- DPR is capped (default 1.5). Quality tiers lower DPR, blur passes, aberration and frost. `auto` starts from device hints, steps down after sustained slow frames, and never steps back up.
- WebGL context loss is handled: lenses fall back to CSS and recover when the context is restored.

Measured numbers and methods are in [docs/perf.md](https://github.com/MahbodHastam/liquid-glass/blob/main/docs/perf.md). Real-device mobile numbers are still pending.

## Browser support

WebGL2: Chrome/Edge, Firefox, and Safari 15+ (desktop and iOS). The e2e suite runs on Chromium, Firefox and WebKit. Where WebGL2 isn't available, the CSS `backdrop-filter` fallback stays in place.
